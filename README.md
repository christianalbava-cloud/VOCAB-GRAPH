# VocabGraph

A personal vocabulary learning tool for systems engineers learning English.
Words become nodes in an interactive knowledge graph. Every time you add a word
an AI generates a full learning card, finds semantic links to words you already
know, and draws live connections in the graph.

---

## What makes this app useful

- **Knowledge graph** — words are nodes; the AI draws edges based on semantic
  similarity. Clusters form naturally (concepts on the left, phrases on the
  right, composed expressions at the bottom).
- **Full learning card per word** — definition, 3 labelled examples, phrases
  to use in meetings, mnemonics, and related words — all generated by the LLM.
- **Verb tenses tab** — conjugation table with 3 example sentences per tense,
  streamed on demand.
- **Speak tab** — practical phrases to use in real work conversations.
- **Listen button** — browser Text-to-Speech pronounces any word in American
  English with one click (no API needed).
- **Phrase Builder** — click multiple nodes, hit Analyze, and the AI explains
  how those concepts connect and whether they form a real English expression.
- **Category filter** — toggle Concept / Phrase / Composed visibility in the
  graph in real time.
- **Export / Import** — full graph backup and restore as JSON.
- **Works offline** — Ollama provider runs 100 % locally, no internet required.

---

## Requirements

- Python 3.10+
- A running LLM — either **Ollama** (local, free) or a **Groq** API key (cloud, free tier)

## Installation

```bash
# 1. Clone the repo
git clone <repo-url>
cd Vocab-graph

# 2. Install Python dependencies
pip install -r requirements.txt
```

### Ollama — install the local model

```bash
# Install Ollama (Windows / macOS / Linux)
# https://ollama.com/download

# Pull the model used by this project
ollama pull qwen2.5-coder:7b

# Keep Ollama running in the background
ollama serve
```

### Groq — get a free API key

1. Create a free account at <https://console.groq.com>
2. Go to **API Keys** → **Create API Key**
3. Copy the key — you will use it in the config step below

## Configuration

All config is done through environment variables.
You can set them in a `.env` file or export them in your terminal.

### Run with Ollama (default — no extra config needed)

```bash
# These are the defaults; you only need to set them if you changed something
LLM_PROVIDER=ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5-coder:7b
```

**Recommended Ollama model:** `qwen2.5-coder:7b`
A 7-billion-parameter model that fits on most machines (≈ 4 GB RAM).
Other options that work well: `llama3.2:3b` (lighter), `qwen2.5:14b` (smarter).

### Run with Groq (cloud, fast, free tier)

```bash
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_...          # your key from console.groq.com
GROQ_MODEL=llama-3.3-70b-versatile
```

**Recommended Groq model:** `llama-3.3-70b-versatile`
70-billion parameters, very fast on Groq hardware.
Other free options: `llama-3.1-8b-instant` (faster, lower quality),
`gemma2-9b-it` (good balance).

**Free tier limits:** 14 400 requests / day, 14 400 tokens / minute — more
than enough for personal use.

## How to run

### Windows — Ollama

```bat
set LLM_PROVIDER=ollama
uvicorn main:app --reload --port 8000
```

Then open <http://localhost:8000> in your browser.

### Windows — Groq

```bat
set LLM_PROVIDER=groq
set GROQ_API_KEY=gsk_...
uvicorn main:app --reload --port 8000
```

### macOS / Linux — Ollama

```bash
LLM_PROVIDER=ollama uvicorn main:app --reload --port 8000
```

### macOS / Linux — Groq

```bash
LLM_PROVIDER=groq GROQ_API_KEY=gsk_... uvicorn main:app --reload --port 8000
```

### Using a .env file (any OS)

Create a file named `.env` in the project root:

```env
# choose one provider block and delete the other

# --- Ollama ---
LLM_PROVIDER=ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5-coder:7b

# --- Groq ---
# LLM_PROVIDER=groq
# GROQ_API_KEY=gsk_...
# GROQ_MODEL=llama-3.3-70b-versatile
```

Then run:

```bash
pip install python-dotenv          # one-time
uvicorn main:app --reload --port 8000
```

> **Note:** add `.env` to your `.gitignore` so you never commit your API key.

**API endpoints**

| Method | Path | What it does |
|--------|------|--------------|
| GET | `/api/nodes` | List all words |
| POST | `/api/nodes` | Add a word |
| DELETE | `/api/nodes/{id}` | Remove a word |
| GET | `/api/links` | List all connections |
| POST | `/api/links/batch` | Save multiple links |
| GET | `/api/ai/stream/{word}` | Stream learning card (SSE) |
| POST | `/api/ai/similarity` | Score word vs existing nodes |
| POST | `/api/ai/spellcheck` | Check spelling before saving |
| POST | `/api/ai/phrase` | Analyze a phrase combination |
| GET | `/api/ai/tenses/{word}` | Stream verb tenses card (SSE) |
| GET | `/api/export` | Download full graph as JSON |
| POST | `/api/import` | Upload and merge/replace graph |

## What happens when you add a word

```
User types "idempotent" in the + Add Word modal
│
├─► [1] Spell check
│       POST /api/ai/spellcheck
│       AI checks: is the spelling correct?
│       ├─ Wrong → show suggestion ("idempotant → idempotent")
│       └─ Correct → proceed
│
├─► [2] Save node
│       POST /api/nodes  { id: "idempotent", cat: "concept", notes: "..." }
│       Stored in SQLite → new node appears in the graph immediately
│
├─► [3] Stream learning card
│       GET /api/ai/stream/idempotent
│       LLM generates (streamed live to the detail panel):
│         ## DEFINITION        — plain-English explanation
│         ## EXAMPLES          — Systems Engineering / General / Conversation
│         ## HOW TO SPEAK      — 3 phrases for meetings
│         ## IDEAS TO REMEMBER — 3 mnemonics / analogies
│         ## RELATED WORDS     — 5 related terms
│       Result saved to ai_cache column in SQLite
│
├─► [4] Semantic similarity
│       POST /api/ai/similarity  { word, existing: [...all other nodes] }
│       LLM scores the new word against every existing node (0–1)
│       Scores ≥ 0.5 → links are created
│         score ≥ 0.75 → thick green line  (strong link)
│         score  0.5–0.75 → thin grey line (weak link)
│
└─► [5] Graph reloads
        New node + its links appear
        D3 force simulation repositions everything
        Node is highlighted and detail panel stays open
```
